## 説明 ##
マインスイーパーとターン制バトルを組み合わせたゲームです。
## 使用技術 ##
python,Vscode
## 製作期間 ##
2025年 8月
## アピーㇽポイント、工夫点 ##
今までは既存のターン制バトルを真似たもの を作ってきましたが今回はオリジナルっぽいものを 作ってみたかったのでマインスイーパーと ターン制バトルを掛け合わせたものを作りました。<br>
こういった何かと何かを掛け合わせてゲームを作る経験は 初めてだったので戸惑いましたが、マインスイーパーの結果を バトルの攻撃力や防御力に反映したり、バトルで 使用したらマインスイーパーが有利になる道具を 実装することによって上手く二つの要素を 掛け合わせることができたと思います。<br>
2025年1月には一旦完成としていたのですが タイトルやチュートリアル、BGMなどの要素を追加し、 ちゃんとしたゲーム作品として2025年7月にインターネット に公開しました。<br>
アイテムなど一部イラストは自作しました、これもアピールポイントです。<br>
プレイされる場合は「操作説明書.txt」をご一読ください。
