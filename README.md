## 説明 ##
マインスイーパーとターン制コマンドバトルを合わせたゲーム<br>
マインスイーパーとターン制コマンドバトルを組み合わせたゲームをPythonを用いて制作しました。<br>
作成期間は2024年11月から2025年6月ですが、2024年12月に一度作成を終了した後、2025年5月に再開したので実際の開発期間はもっと短いです。<br>
ゲームの流れは、まず各ターンの開始時に一定時間マインスイーパーをプレイし、発見した爆弾の数に応じてエネルギーを獲得します。次に、そのエネルギーを攻撃や防御に割り振ることで行動を行い、その後に敵の行動が実行されます。このサイクルを、敵を倒す、またはプレイヤーが倒されるまで繰り返します。<br>
## 使用技術 ##
python,Vscode
## 製作期間 ##
2024年 12月~2025年 6月
## 制作理由 ## 
本ゲームを作成した理由は、ただ既存のゲームを模倣するのではなく、新しいゲームを制作したいと考えたからです。しかし、本ゲーム制作当時は経験が浅かったため、既存の要素を組み合わせる形で新規性を生み出す方針を取りました。<br>
その一つとして、以前に趣味で制作した経験のあるターン制コマンドバトルを採用しました。加えて、バトルとは無関係なゲームでありながら、結果が爆弾の発見数という明確な数値で表されるマインスイーパーに着目しました。
この数値をバトルにおけるステータスとして活用できると考え、両者を組み合わせたゲームを制作しました。

## アピールポイント、工夫点(技術的)
①マインスイーパーエリアの実装<br>
マインスイーパーエリアの実装についてはマインスイーパーを描画する座標(マインスイーパーの左上)を設定し、そこからfor文を用いて設定した行数と列数の数だけ描画を繰り返したあと、枠線を描画することでマインスイーパーのエリアを描画しています。また、そのマスが開かれているか、爆弾かどうかでどんなふうに描画するかを切り替えています。 さらに、マインスイーパーのクリック時にはクリックされた座標からマインスイーパーエリアの基準座標を減算し、それをさらにマス目のサイズで割ることでクリックされたマス目を取得しています。<br>
具体的な数字で説明すると、座標(90,140)がクリックされた時マスのサイズが40×40、マインスイーパーエリアの基準座標(左上)を(50,100)だとすると、x軸では (90 - 50) ÷ 40 = 1,y軸では (140 - 100) ÷ 40 = 1となり、クリックされたマス目は一番左上のマスであることが分かります。<br>
<br>

②マスの爆弾の数を数える関数の実装<br>
マインスイーパーのマスの周りにある爆弾を数える関数を実装しました。<br>
具体的には引数で取得したマスの行数、列数に対し、for文を用いて行列ともに-1,0,1の範囲で探索を行って前後左右斜めの探索を行います。
その探索の中で生成された配列の範囲に含まれているかつ、爆弾のマスがあった時にカウントを行い、その結果を戻り値に設定しています。<br>
探索範囲を具体的に示すと以下の様になります。<br>
選択されたマス : A<br>
探索範囲 : x<br>
<br>
x x x<br>
x A x<br>
x x x<br>
<br>
③再帰的に周りにある爆弾の数が0のマスを開く関数の実装<br>
再帰的に周りにある爆弾の数が0のマスを開く関数を実装しました。<br>
探索の仕方は②で説明した関数と同じです。探索したマスの中で生成された配列の範囲内かつ、まだ開かれていないマスがあればそのマスを開き、その開いたマスの周りにある爆弾が0この場合、そのマスに対してこの関数を再帰的に実行することで選択したマスの周りにある爆弾が0のマスを再帰的に開くように実装しました。<br>

## アピールポイント、工夫点(技術的でない) ##
アピールポイント①:2つのジャンルの融合<br>
マインスイーパーとターン制コマンドバトルという2つのジャンルを、一つのゲームとして成立させた点です。
マインスイーパーでの成果（爆弾の発見数）をバトルのエネルギーに変換することで、両者の要素を自然に結びつけました。<br>
<br>
アピールポイント②:リスクとリターンを連動させる難易度設計<br>
ターンが進むごとに爆弾の数を増加させ、マインスイーパーの難易度が段階的に上昇するように設計しました。
その一方で、爆弾数の増加により獲得できるエネルギーの上限も上がるため、難易度の上昇と報酬の増加が両立する「リスクとリターン」のバランスを実現しました。<br>
<br>
アピールポイント③:アイテムによるランダム要素の追加<br>
アイテムを実装し、ランダムに取得できるようにしました。
これにより、マインスイーパーが苦手なプレイヤーでも戦略の幅を広げやすくし、プレイ体験の単調化を防いでいます。<br>
<br>
アピールポイント④:チュートリアルと操作方法の表示<br>
本ゲームは一般的なゲームとは異なる操作体系を採用しているため、キーボード操作が中心である点も含め、初回プレイをチュートリアルとして設計しました。<br>
また、プレイ中も操作方法を常に画面上に表示することで、プレイヤーが迷わずゲームを進められるよう工夫しました。
<br>
アピールポイント⑤:一部イラストの自作による統一感<br>
アイテム使用時のイラストを自作することで、ゲーム全体の世界観とデザインの統一を図りました。<br>
